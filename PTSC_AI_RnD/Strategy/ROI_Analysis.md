# 📊 ROI Analysis Framework

## Cách tính ROI cho AI Use Case

### Công thức cơ bản

```
ROI = (Giá trị tiết kiệm - Chi phí triển khai) / Chi phí triển khai × 100%
```

### Giá trị tiết kiệm

```
Giá trị tiết kiệm/năm = Số người × Tần suất/tuần × Thời gian/lần × 52 tuần × Chi phí nhân sự/giờ
```
